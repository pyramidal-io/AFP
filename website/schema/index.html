AFP Wire Artifacts

The native credential-only session carrier is specified by afp:credential-envelope:v1 (§12.7.2), with the machine-readable shape at schemas/afp-credential-envelope-v1.schema.json in the AFP source distribution. ZKC owns the presentation and authenticated proof request inside it. AFP v0.3.14-draft does not publish active schemas for the retired v0.2 agent manifest, discovery, task delegation, or HTTP bridge surfaces.

Current wire artifacts are specified normatively in the AFP specification: afp:witness-bootstrap:v1, afp:rotation-presentation:v1, afp:telemetry-sample-binding:v1, afp:zkc-presentation-context:v2, afp:mixnet-directory:v1, afp:session:v1, afp:envelope:v1, afp:payment-quote:v1, afp:payment-receipt:v1, afp:payment-policy:v2, afp:payment-quote:v2, afp:payment-receipt:v2, and profile descriptors. The current presentation context maps its SHA-256/JCS digest to one canonical nonzero BN254 scalar; it is not an arbitrary 32-byte digest on the proof wire.
