# Agent Federation Protocol (AFP)

AFP is a protocol specification and standard-library reference snapshot for
privacy-preserving, verifiable agent federation.

The normative AFP specification set (the [core](docs/afp_specification.md),
whose §11 lists every member: the
[AFP Federation Mixnet](docs/afp_routing_specification.md), the
[`afp.introduction` profile](docs/afp_introduction_profile.md) and
[AFP-KDC](docs/kdc_specification.md)), companion
[protocol-family interfaces](protocol-family/README.md), and
[Python reference package notes](python/README.md) are included in this
snapshot. See [CONTRIBUTING.md](CONTRIBUTING.md) for the limits of changes to
a generated snapshot and [SECURITY.md](SECURITY.md) for private vulnerability
reporting. [Snapshot provenance](docs/public-snapshot-provenance.md) explains
the public-tree boundary and history separation.

Consumer-facing release changes are recorded in the [changelog](CHANGELOG.md).
