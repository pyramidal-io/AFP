# Contributing to this snapshot

This repository is a generated public snapshot of reviewed AFP protocol and
reference material. It does not accept direct changes as an authoritative
development source.

Use the repository's issue and discussion channels for questions or proposed
improvements. A future snapshot may incorporate reviewed changes, but a pull
request here does not by itself change AFP or guarantee inclusion in another
snapshot. For vulnerabilities, follow [SECURITY.md](SECURITY.md).

## Public changelog and release policy

The public [changelog](CHANGELOG.md) records consumer-facing changes only; it
is not a reconstruction of every internal commit. Use the applicable headings
`Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security`, and
`Compatibility`. Security details may be withheld while an embargo is active;
publish a consumer-safe summary when disclosure is appropriate.

Compatibility entries must state any affected wire version or the absence of a
wire version change. A release tag must be exactly `v<spec Version>`, match the
normative specification version, and have a matching dated changelog heading.
